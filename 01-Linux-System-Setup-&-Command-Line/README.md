# Lab 01: Linux System Setup & Command Line

**Difficulty:** Beginner  
**Environment:** Ubuntu Linux running in Oracle VirtualBox

## Overview

This lab focused on becoming familiar with the Linux command line and learning how to navigate and interact with the Ubuntu filesystem.

The exercises provided practical experience with directory navigation, file creation, viewing and editing text files, and identifying basic system information.

## Objectives

- Become comfortable navigating the Linux filesystem.
- Create and manage files and directories.
- View and edit text files from the terminal.
- Identify the current user and hostname.
- Inspect basic Linux system and kernel information.

## Environment

- Operating system: Ubuntu Linux
- Virtualisation software: Oracle VirtualBox
- Interface: Linux Terminal
- Shell: Bash (default Ubuntu shell)

## Commands Practised

### 1. Filesystem Navigation

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories. |
| `ls -la` | Displays detailed directory contents, including hidden files. |
| `cd` | Changes the current directory. |
| `cd ..` | Moves to the parent directory. |
| `cd ~` | Returns to the user's home directory. |

### 2. File and Directory Operations

| Command | Purpose |
|---|---|
| `mkdir` | Creates a new directory. |
| `touch` | Creates an empty file. |

### 3. Viewing and Editing Files

| Command | Purpose |
|---|---|
| `cat` | Displays the contents of a file. |
| `nano` | Opens a terminal-based text editor for creating and editing files. |

### 4. Basic System Information

| Command | Purpose |
|---|---|
| `whoami` | Displays the currently logged-in username. |
| `hostname` | Displays the computer's hostname. |
| `uname -a` | Displays kernel and system information. |

## Testing and Verification

The commands were executed in the Ubuntu terminal to practise filesystem navigation, basic file operations, text editing and system identification.

No command errors were encountered during the exercises.

## Skills Practised

- Linux command-line navigation.
- Basic filesystem management.
- Creating directories and files.
- Reading and editing text files.
- Identifying the current user and system hostname.
- Inspecting basic Linux system information.

## Conclusion

This lab provided a practical introduction to working with Ubuntu through the terminal. It established a foundation in Linux command-line navigation, basic file management and system identification.

These skills will be useful when working with Linux-based systems in IT support, system administration and cybersecurity environments.
